# browser-designs

Hub for creating and showcasing beautiful, highly-polished web UI designs using Vanilla CSS.

## Commands
- `pnpm install`
- `pnpm dlx playwright install chromium` (Run this once to install the Playwright browser driver)
- `pnpm dev`

## Tools
### Screenshot utility
You can capture full-page screenshots of reference websites and save them directly to `docs/design-references/` for AI distillation:
```bash
pnpm run screenshot https://example.com example.png
```
